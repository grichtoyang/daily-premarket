# V9 Pro — Analysis Layer Skill（正式版）

版本：1.0｜定版日期：2026-11-14
適用版本：V9 Pro 17F
狀態：六分頁已完成使用者驗收；除新證據或明確授權外維持凍結。

## 1. 分析層職責

分析層使用既有 DATA_REPORT／Dashboard JSON，將數據轉化為可理解、可交叉檢查、可執行觀察的市場解讀。不得擴張資料層、虛構欄位、填補缺值或將推論寫成事實。

每個分析區塊以「分析／判斷／操作」組織：
- 分析：數據、單位、基準、時間範圍、觀察到的現象。
- 判斷：交叉證據、支持與反向訊號、信心及限制。
- 操作：觀察位、觸發、確認、失效與風險控制；未形成條件時明確等待。

文字必須比圖表多提供一層意義，不可只是重複數字；也不可為了長度堆疊術語。

## 2. 全域判讀鐵律

1. 同一比較必須使用同一法人群、同一時段、同一市場範圍及一致單位。
2. OI 是存量，日／夜盤交易是流量；不能把 OI 變化描述成當日淨交易口數。
3. 單日快照只支持單日觀察；沒有同口徑多日序列，不得寫成連續增減。
4. 零值是有效中性資料，缺值則是不可判讀；不得把缺值當零。
5. 代理／估算值不可描述為真實現金流、實際 Delta／Gamma 曝險或官方持倉。
6. 單一指標、單一法人或單一市場不能直接證明趨勢。
7. 反向訊號必須揭露；資料不足、訊號背離時降低信心，不形成方向共識。
8. 交易方向必須由價格結構觸發；籌碼與 Bias 只作背景確認。
9. 不虛構勝率、機率、停損點數、固定波動距離或未經回測的策略績效。
10. 所有數字與關鍵位必須來自當日 Dashboard payload 或明確標示的衍生計算。

## 3. 六分頁職責與正式標準

### 3.1 總覽

目的：提供全市場決策摘要，不複製重大新聞清單，也不與專業分頁產生矛盾結論。

- KPI 僅作快速狀態摘要；單位、正負號與時間範圍須清楚。
- Bias 顯示總體背景與因子貢獻，不是勝率、預測機率或單獨進場訊號。
- Bias 分析須交代中性基準、有效因子數、權重覆蓋率、有效因子重新正規化及缺失／停用因子。
- 因子圖若只顯示前 8 項，必須明確說明是可見子集合，不代表全部因子。
- 三大法人快照需區分外資、投信、自營及合計；單日資料不可冒充連續趨勢。
- 期選結構須區分 PCR、OI、GEX、Call／Put Wall、Gamma Wall、Flip、Max Pain 的口徑及限制。
- 價格趨勢與關鍵水位須使用實際日期序列；五日走勢不得填造缺失日期。
- 總覽重大新聞區塊已移除，避免與「重要市場」新聞重複；重大新聞以重要市場分頁為主。
- 最終操作文字須連結 Bias、籌碼、期選結構及價格觸發，不得把 Bias 當進場訊號。

Bias 計算示例僅供解釋：2026-11-06 的 17F 畫面為中性基準 50、有效因子加權貢獻合計 -11.22、結果 38.78、四捨五入 39；有效因子 14/17、原始基礎權重覆蓋 85.6%，有效權重重新正規化為 100%。這些是該日樣本，不是固定常數或所有日期預設值。

### 3.2 現貨

目的：解讀加權指數、上市／上櫃廣度、法人現貨、融資融券／借券及成交結構。

- K 棒紅黑依開盤與收盤比較；單日漲跌幅依前收比較，兩者可能不同向。
- 解讀收盤在當日高低區間的位置、上下影線與實體；不得單靠 K 棒宣稱反轉。
- 市場廣度須分上市與上櫃，並交代合計或分市場淨漲跌家數；缺值不可當完整樣本。
- 法人買賣超需同時檢查外資、投信、自營是否分歧；合計不能掩蓋分項背離。
- 融資餘額與增減須分開；若缺少前一日基期，不得將增減絕對值包裝成標準日變動率或直接宣稱去槓桿。
- 借券餘額、借券賣出餘額、借券賣出增減與融券是不同欄位；借券資料不等同新增空方淨部位。
- 成交結構需分上市／上櫃金額與占比；成交占比不等於歷史量能擴張。
- 交叉分析至少涵蓋價格、廣度、法人籌碼；並在風險區塊交代融資、借券、成交結構的限制。
- 反彈判讀必須確認是否收復前收或關鍵位置；下跌日內收紅 K 不等於趨勢反轉。
- 操作採階段式：觀察區、收復／突破確認、失效條件；不把當日高低點直接定義成必然支撐壓力。

### 3.3 重要市場

目的：將美股、亞洲市場、美股期貨、公債殖利率、匯率、ADR、原物料／加密資產與重大新聞整合為外部風險背景。

- 每一市場資料須標示來源基準、報價單位、變化單位及時間；不可直接比較不同幣別或不同市場的原始數值。
- 殖利率水準用 %，日變化用 pp；2Y–10Y、10Y–20Y、20Y–30Y 曲線斜率需依實際利差分類，不得把單日斜率變化直接推成景氣結論。
- VIX 必須區分指數水準與變化，參考門檻只作風險分級，不代表必然市場方向。
- 美股指數與 SOX 需區分指數點數及漲跌幅；單一科技指數上漲不等於整體市場風險解除。
- 重大新聞來源以 DATA_REPORT 第 8 節「重大經濟數據、央行事件與重大市場新聞」為依據，並保留標題、摘要、來源與原始時間資訊。
- 新聞依 T0 前／T0 後／時間未核實分類；需先解析來源時間戳再作 T0 截止，不可只用字串排序或猜時區。
- 重大新聞卡片採全寬，避免與其他市場卡片並排壓縮；重要商品區塊亦維持可讀寬度。
- 新聞是事件背景，不得單靠標題推定台股方向；需搭配市場價格與風險資產反應。
- 不得在總覽再重複放置重大新聞清單。

### 3.4 期貨

目的：分開解讀日盤與夜盤價格、基差、法人 OI 存量、日夜盤淨交易流量及前十大部位。

- 日盤 OHLC 與夜盤 OHLC 各自採正確盤別基準；夜盤自身漲跌不得與夜盤收盤相對日盤收盤的跨盤差值混為一談。
- 基差與正／逆價差需說明定義及單位。
- OI 是持倉存量；日／夜盤淨交易是該時段流量，兩者不可直接相加或相減。
- 帶正負號的淨部位變化須同時看數值方向與變化量：往正方向移動代表多方部位相對增加（可能是淨多擴大或淨空縮小）；往負方向移動代表空方部位相對增加（可能是淨空擴大或淨多縮小）。不能只看絕對值大小。
- 前十大與三大法人是不同群體，必須分開比較。
- 外資流量需按實際價格方向動態解讀：價格升＋淨買、價格跌＋淨賣為初步同向；價格升＋淨賣、價格跌＋淨買為背離；一致也不代表趨勢已確認。
- 夜盤流量為 0 是有效中性值；缺值則無法判讀。兩者須使用不同文字分支。
- 若夜盤收盤高於日盤收盤，次日觀察能否守在日盤收盤之上；若低於，觀察能否重新站回；若相等，等待有效站上或跌破。
- 操作條件需結合價格、流量與關鍵位；不得用單日 OI 快照推論當日加碼／減碼。

### 3.5 選擇權

目的：解讀成交量、OI、PCR、履約價分布、法人流量、GEX 與模型關鍵價位。

- PCR 固定為 Put OI ÷ Call OI，單位倍；Call／Put 成交量占比是另一指標。
- Call／Put OI 分布、Top10、Wall 與 Gamma 指標須分別解釋，不能互相代替。
- OI 是存量；日／夜盤淨口數是流量；前十大快照變化須注意到期月份與換月口徑。
- 選擇權法人日夜淨口數與法人多空力道金額分開呈現；不可混用單位或將買賣淨口數直接判成方向。
- GEX 是 OI-based Black-Scholes 模型估值，標示 NT$／標的價格變動 1%；模型假設不代表造市商真實持倉。
- Gamma Wall、Gamma Flip、Max Pain、Call Wall、Put Wall 各有不同定義；不得將其統稱成確定支撐／壓力。
- 缺少有效 Flip 時顯示 unavailable，不可填 0 或推定方向。
- 操作區塊以價位作觀察條件；未確認有效突破／跌破前，不把模型價位當作已生效的支撐或壓力。

### 3.6 綜合分析

目的：將現貨、期貨、選擇權及日夜盤資料整合成一致的跨市場判讀與交易計畫；不是重複各專業分頁全文。

- 優先以同一法人群比較現貨外資日盤買賣超與期貨外資日盤淨交易，只比較方向符號，不比較金額大小；兩市場曝險不同，不代表等價權重。
- 這兩項是主要日盤方向檢查。兩項均可用且符號一致，僅表示兩個可比較訊號一致，不代表全市場法人共識、勝率或發生機率；少於兩項不形成完整確認。
- 期貨外資夜盤淨交易另行檢查；若與日盤訊號反向，降低信心。夜盤為 0 是中性，不可當缺值，也不能作方向確認。
- 選擇權買賣淨口數未拆 Call／Put，只作交易活動背景，不作多空方向投票。
- 選擇權契約金額代理值是依買賣方向與 Call／Put 分類的金額差額，不等同淨權利金現金流或實際 Delta／Gamma 曝險；只作次級方向線索，不視為與現貨／期貨等價的第三票。
- 選擇權日夜代理值正負相反代表時段分類差額分歧，不代表夜盤已反轉日盤或法人整體翻多翻空。
- 全體法人現貨／選擇權合計作背景，不可與外資欄位混成同一法人群投票。
- OI 仍為存量，不能納入日夜交易流量投票。
- Bias 與因子貢獻只作背景交叉檢查；圖表前 8 項僅為可見子集合。
- 交易計畫包含多方候選、空方候選與區間觀察：多方須有效站上 Call Wall 並回測守穩；空方須有效跌破 Put Wall 並反抽無法收復；區間內不追價。
- 方向確認需同時符合日盤現貨／期貨訊號、夜盤檢查及選擇權代理值限制；有反向或缺值時降級為觀察。
- 因子與日夜盤資料是交叉檢查，不取代價格觸發、回測確認及風險控制。
- 交易計畫須明列觸發、確認、失效及風險條件；沒有依據時不虛構固定停損點數。

## 4. Bias 與因子品質

- Bias 是加權背景分數，不是預測機率或勝率。
- 必須揭露中性基準、有效因子數、原始權重覆蓋率、有效因子權重重新正規化及未納入因子。
- 缺值因子不能視為 0 分；有值但未設方向化規則的因子應列為 disabled，而非 missing。
- 只顯示部分因子時，清楚標示圖表顯示範圍。
- 任何因子方向、權重與計算方式以 Template 當前實作為準；文件不可自行創造權重或門檻。

## 5. 交易計畫通用規則

每一方向性情境均需：
1. 觸發：價格有效突破／跌破哪一既有關鍵位。
2. 確認：守穩、回測、反抽失敗，及相關流量是否配合。
3. 失效：價格重新站回／跌回何處，或關鍵證據反轉。
4. 風險：若無法依資料推導停損距離，明確保留使用者依商品波動與部位風險設定，不得虛構點數。

「籌碼偏多／偏空」不是交易觸發；「碰到 Wall」也不等於有效突破或跌破。

## 6. 分析層驗收

- 檢查每個分析段落是否能對應實際資料與計算。
- 驗證零值、缺值、反向訊號及資料不足分支。
- 以合成案例測試條件分支時，標示為合成案例 PASS，不得等同真實行情驗證。
- 自動化文字檢查通過不等於真實市場分析合理性已通過。
- 使用者實際畫面驗收與資料來源正確性分開標示。
- 本版本六分頁已完成使用者驗收；未經授權不得主動重開。
