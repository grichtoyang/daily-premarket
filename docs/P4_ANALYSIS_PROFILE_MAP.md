## 使用規則

- 每個區塊有獨立 profile；可共用計算工具，但不得共用無關的分析文字。
- 分析輸出固定包含：證據、關係／背離、有限度判斷、反證／失效條件、操作觀察、資料限制。
- 數字只能引用該區塊可見且有效的欄位；單位、日期、來源口徑必須一致。衍生值須能由該區塊可見值重算。
- 缺值、過期、來源不一致或品質不足時，降低結論等級；不可補零、猜測或使用其他區塊的數字冒充本區塊證據。
- 不得把單一指標轉成因果、預測機率、勝率或無條件買賣指令。
- 本表是 profile 規格草案，不代表 42 個 profile 已接入 runtime，也不代表已達 95 分品質。
